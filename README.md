
# Monopolypoly

Le jeu du Monopoly en local, en **TypeScript**, **HTML**, **CSS** et sans IA.


## Run Locally

Clonez le projet

```bash
  git clone https://github.com/Gwenos/monopoly.git
```

Allez à la racine du projet

```bash
  cd monopoly
```

Installez les dépendances

```bash
  npm install
```
Lancer le serveur

```bash
  vite
```
